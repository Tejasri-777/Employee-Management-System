# Employee Management System

## Project Overview

Employee Management System is a Full Stack Web Application developed using Angular, Spring Boot, and MySQL.

The application allows organizations to manage employee information efficiently through a user-friendly interface and RESTful backend services.

---

## Features

### Employee Management

- Add New Employee
- View Employee List
- View Employee Details
- Update Employee Information
- Delete Employee Records

### Additional Features

- Pagination Support
- Responsive User Interface
- REST API Integration
- MySQL Database Connectivity

---

## Database Setup

1. Create a MySQL database:

```sql
CREATE DATABASE employee_management_system;
```

2. Import the database script available in:

```text
database/ems.sql
```

---

## Backend Setup

Navigate to:

```text
backend/EmployeeMSBackend
```

Run the Spring Boot application.

Backend runs on:

```text
http://localhost:8081
```

---

## Frontend Setup

Navigate to:

```text
frontend/employee-management-frontend
```

Install dependencies:

```bash
npm install
```

Run Angular application:

```bash
ng serve
```

Frontend runs on:

```text
http://localhost:4200
```
